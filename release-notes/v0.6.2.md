# CodeConfigHub v0.6.2

## 本次重点

- 重构 Schema 编辑区，减少大配置场景下的纵向滚动
- 扁平化分类页层级，进入详情分类后不再套过深折叠
- 优化左侧导航栏背景层次，提升整体观感和区块区分度
- 统一为下拉框补充箭头图标，交互更清晰

## 新增与优化

- 新增更适合大字段量场景的 Schema stage 布局，让分组导览与内容编辑区协同展示
- 对高频字段区域进行密度优化，减少“数据一多就要一直下滑”的问题
- 非“全部 / 常用”分类页直接进入当前分组内容，减少无意义层级
- 下拉框统一增加内置 chevron 图标，提升可识别性
- 左侧侧栏背景重新做了分层处理，并修正了背景里不自然的硬直角观感

## 修复

- 修正左侧导航栏背景过渡不自然的问题
- 修正分类详情层级过深带来的连续编辑体验问题

## 升级说明

- 无破坏性变更。
- 现有配置文件与安装升级流程保持兼容。

## Release 资产

- Windows 安装包：`CodeConfigHub-Setup-0.6.2.exe`
- 增量更新元数据：`latest.yml`
- 增量更新 blockmap：`CodeConfigHub-Setup-0.6.2.exe.blockmap`
